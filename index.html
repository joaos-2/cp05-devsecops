O pipeline de segurança obrigatório

Depois do vazamento de uma chave de API num commit público, a diretoria tornou obrigatório um pipeline de segurança em todo repositório. Este portal passou a rodar com três barreiras automáticas que impedem código inseguro de chegar à produção.

Gitleaks

Varre o repositório e o histórico de commits atrás de segredos (chaves, tokens, senhas) e barra o push se encontrar.

Semgrep

Análise estática do código-fonte (SAST). Aponta padrões perigosos como o uso de eval() antes do merge.

Trivy

Escaneia a imagem Docker e bloqueia a publicação se houver vulnerabilidade (CVE) crítica.

Como o container funciona: namespaces e cgroups

Um container não é uma máquina virtual. Ele é um processo comum do Linux, rodando no mesmo kernel do servidor, mas com dois recursos aplicados sobre ele: namespaces, que isolam o que ele enxerga, e cgroups, que limitam o quanto ele pode consumir.
